适用范围

提词兔 CueBunny 是面向 iPhone 和 iPad 的提词与录制应用。本政策适用于应用及本开发者网站。产品由 GitHub 账户 FZelinda 维护。隐私与产品相关问题可通过支持页面联系维护者。

提词兔不要求注册账户，不含广告或第三方分析 SDK，也不运营上传稿件、录制内容或转写结果的服务器。我们不出售你的个人信息，不使用你的内容训练 AI 模型。

稿件、媒体与权限

稿件、导入文档、录制内容、编辑设置、字幕及导出文件均在设备本地处理与保存。文件访问限于应用自身文件和你主动选择的文件。若选择云盘中的文件，相应服务可能先将文件下载到设备。

相机权限用于拍摄提词；麦克风权限用于视频录制、纯录音、屏幕讲解及语音跟读；系统本地语音接口需要时会请求语音识别权限。主动将导出视频保存到照片时才请求“仅添加”权限，提词兔不请求浏览整个相册的权限。你可在 iOS 设置中调整这些权限。

本地语音处理

语音跟读与转写使用 Apple 提供的本地语音能力，是否可用取决于设备、系统版本和所选语言。较早的识别接口明确要求本机识别，较新的接口使用系统本地语音模型。本地识别不可用时，应用会说明限制，不会改用云端转写。

你选择准备语音能力后，所需语言模型可能需要通过 Apple 系统服务下载。下载需要联网，并适用 Apple 的服务政策；这不改变音频仅在本机识别的要求。支持某种界面语言不代表支持该语言的语音识别。跟读过程中产生的识别文字在本机处理，保存的字幕会成为本地项目的一部分。

屏幕录制与悬浮提词

悬浮提词使用 iOS 画中画，屏幕讲解使用 Apple ReplayKit。系统广播可用且由你主动开启时，录制扩展会将画面及音频样本写入本机共享 App Group 目录，供提词兔读取成片，不会传送到开发者服务器。

共享目录可能暂存录制片段、状态文件，以及由已验证购买权益生成的短期本地录制许可，用于录制衔接与恢复。录屏可能包含系统允许录下的屏幕内容；你可通过系统录制指示停止。其他 App 和受保护内容可能限制录制。

保存、备份与删除

应用稿件库及录制目录不纳入设备或 iCloud 备份，提词兔不提供云同步或云端恢复。删除应用或更换设备前，请在应用外保留重要稿件和导出文件。应用内部的稿件恢复快照只是本地恢复资料，并非外部备份。

删除稿件会将稿件及相关片段移入“最近删除”，你可从中恢复或确认永久删除。永久删除会清除该稿件及未被其他保留稿件引用的文件，并移除本地恢复快照中的对应记录。其他媒体和已导出副本可能独立保留。删除 App 会移除其本地应用数据；仅卸载 App 以释放空间可能保留数据。已保存到照片、文件或其他服务的副本仍由你在相应位置管理。

偏好设置与本地次数记录

提词兔通过设备本地偏好设置（UserDefaults）保存新手引导进度、阅读设置、阅读位置和相机偏好，用于避免重复引导并恢复你的使用设置。这些偏好不会发送给我们。系统对偏好设置的管理与被排除备份的媒体库分开。

应用会按天在本机记录示例使用、模式开启和会员相关操作的次数，例如展示会员页、开始购买。记录包含日期、操作、可选模式或套餐及次数，最多保留 1,000 条；不含稿件、音频、付款信息或个人标识，不上传。购买流程诊断只在内存保留最多 128 条事件，相关对象或进程重新创建后消失。

购买与分享

Apple 处理订阅、符合资格的首次优惠、终身购买及付款信息。提词兔使用 Apple 已验证的商品、到期和撤销信息，在本机判断功能权限。我们不会收到你的银行卡信息，也不运营收据上传服务器。Apple 的记录适用《Apple 隐私政策》。

保存或分享文件时，由你选择的目标应用、服务或接收方持有其副本，并按各自政策处理。导出或分享不会自动向提词兔维护者发送一份内容。

网站与支持

本网站托管于 GitHub Pages。我们不添加分析脚本、广告追踪器、第三方嵌入媒体或 Cookie。GitHub 为提供和保护服务，会按《GitHub 隐私声明》处理包含 IP 地址在内的技术请求信息。

如果你通过 GitHub Issues 联系我们，你的 GitHub 资料及留言会公开显示。维护者仅使用你主动提供的信息答复和排查问题。请勿公开私人稿件、录音录像、付款信息等敏感内容。支持讨论可能持续保留，直至你、维护者或 GitHub 在平台允许范围内删除；关闭 Issue 不等于删除。

你的选择与联系

你可在 iOS 设置中管理权限，按上述方式删除本地内容，通过 Apple 管理购买，并自行选择分享的资料。我们没有开发者持有的账户或媒体数据库可供检索或删除。对于你在支持中主动公开的信息，可通过支持页面请求更正或移除，同时适用 GitHub 的平台控制。适用的数据保护权利不受影响。

我们不会有意向儿童索取个人信息。处理方式发生变化时，会更新本政策及其日期。

在 GitHub 联系支持

GitHub Issues 公开可见，需要 GitHub 账户。请勿发布私人稿件、录制文件或付款信息。
