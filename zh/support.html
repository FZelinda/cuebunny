CUEBUNNY SUPPORT

使用帮助

从第一次提词，到保存你的下一条作品。

联系维护者

遇到问题时，请提供设备型号、iOS 版本、提词兔版本、所用模式和复现步骤。你可附上已遮挡私人信息的截图；无需上传稿件或录制原件。

在 GitHub 联系支持

GitHub Issues 公开可见，需要 GitHub 账户。请勿发布私人稿件、录制文件或付款信息。

涉及购买、取消或退款，请同时参考 Apple 的账户和购买服务。

常见问题

可以跳过付费页吗？

可以。完成 3 页新手引导后，选择会员套餐或跳过即可进入应用。跳过不会发起购买。你可以体验内置示例，Plus 功能的权限要求会在应用中显示。

如何恢复购买或取消订阅？

使用原购买 Apple 账户，在提词兔内点击“恢复购买”。取消有效订阅时，打开 iOS 设置，点击你的名字，再进入“订阅”。购买终身会员不会自动取消已有订阅。查看 Apple 操作说明。

为什么语音跟读不可用？

语音跟读和转写需要设备、系统和语言支持。请允许所需的麦克风或语音权限，并在提示时准备本机模型。首次准备模型可能需要联网；应用不会回退到云端识别。本地语音不可用时，可以使用定速提词。

悬浮提词能与其他 App 一起使用吗？

悬浮提词使用 iOS 画中画，按设定速度滚动。可用性和麦克风访问取决于 iOS 及另一个 App。悬浮模式目前不提供语音跟读。重要录制前，请先测试你要使用的 App 组合。

录屏为什么没有画面或声音？

ReplayKit 与被录制 App 决定哪些内容可被采集。受保护内容、App 限制或其他录制会话可能影响录制。需要讲解音频时，在系统广播面板打开麦克风；通过系统录制指示停止，再返回提词兔检查成片。只有系统能力可用时才显示跨 App 广播。

可以导入哪些稿件？

可从“文件”导入纯文本、UTF-8/UTF-16 文本、RTF 或带可提取文字的 PDF。扫描图片 PDF 不适用于文字导入。稿件上限为 100,000 字符，导入文件不超过 10 MB；也可以直接粘贴或编写稿件。

内容保存在哪里？

稿件库保存在当前设备，不纳入设备或 iCloud 备份。重要导出内容请在应用外留一份。已删除稿件在永久删除前可从“最近删除”恢复。删除 App 会移除本地应用数据；应用外保存的副本仍在原位置。
